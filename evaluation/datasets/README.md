# Evaluation datasets

- `templates/` — one `<suite>.jsonl.template` per dataset-driven suite, committed to git. These show the exact schema (see `schema.py`) with obviously-placeholder values. They are **not evaluation data** — every field is a `PLACEHOLDER` string and no metric should ever be computed from them.
- `raw/` — real datasets, named `<suite>.jsonl`, matching the `dataset_file` field in `evaluation/config/experiments/<suite>.yaml`. Populated (see `build/`, below) from real, already-existing project sources — ChromaDB, `lex_validator.py`'s mapping tables, `legal_kb.json`, and the one real sample document in this repo — never from an LLM guessing labels. See `DATASET_DESIGN.md` for the purpose/schema/source-of-truth of each dataset and `DATASET_REPORT.md` for current record counts and known gaps.
- `raw/fixtures/` — binary fixtures (PDFs, images) referenced by `file_path` in `document_analysis`, `legal_qa`, and `end_to_end` datasets. Currently holds one real fixture, `fir_0125_bhayandar.pdf` (staged from `sample_pdf/0125 Publish FIR.pdf`).
- `build/` — one `build_<suite>.py` script per dataset that extracts/derives its records from a specific project source, plus `validate_all.py` (schema + cross-dataset integrity checks) and `report.py` (regenerates `DATASET_REPORT.md`). Run `python -m evaluation.datasets.build.run_all` to rebuild everything from current source state.
- `build/corpus/` — the NyayaSetu Legal Benchmark (NSLB) corpus-expansion pipeline: scans a configurable EXTERNAL legal-document corpus (never hardcoded — see `corpus/config.py` and `evaluation/config/corpus.local.yaml.example`), produces `CORPUS_INVENTORY.md`, and appends new, fully-traceable records on top of (never overwriting) the datasets above. See `NSLB_REPORT.md` for the current benchmark size, coverage, and gap analysis. Run in order: `python -m evaluation.datasets.build.corpus.inventory`, then `.corpus.build_from_corpus`, then `.validate_all`, then `.corpus.nslb_report`.

To add a real dataset by hand instead: copy the matching file from `templates/` to `raw/<suite>.jsonl`, replace every placeholder with a reviewed real record, and run `python -m evaluation.cli run --suite <suite>` — the loader in `loader.py` will reject anything that doesn't match the schema in `schema.py`, with an exact file:line pointer.
